# Security

Please report a security problem privately, not in a public issue: use "Report a
vulnerability" on the repository's Security tab on GitHub, or, if that is not available, reach
the maintainer through their GitHub profile. Say what you did, what happened and which commit
you used.

There is no bug bounty.

Hotend has no releases yet; fixes go to the main branch. What the program promises and where
its edges are is in the "Security model" of [README.md](README.md) and in
[ARCHITECTURE.md](ARCHITECTURE.md).
